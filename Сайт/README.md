# Основной сайт OBSIDIAN RUSSIA

[← Главная страница репозитория](../README.md) · [Развёртывание](../docs/DEPLOYMENT.md)

Веб-портал проекта: новости, сведения о серверах, регистрация, личный кабинет, поддержка и административная панель.

## Запуск

Из корня репозитория:

```bash
python dev.py run
```

Основной сайт будет доступен по адресу **http://localhost:8080**. Для отдельного запуска из этой папки используйте `start.bat` или:

```bash
python server.py
```

Создание администратора из корня: `python dev.py admin site`. Администрирование: `http://localhost:8080/admin`.

## Данные и API

Данные сайта хранятся в SQLite, локально через `dev.py` — в `.runtime/site/`; при отдельном запуске — в `Сайт/data/`, если не указан `OBSIDIAN_DATA_DIR`. Делайте резервные копии через `python dev.py backup site`.

- `GET /api/news` — опубликованные новости.
- `GET /api/status` — список серверов, **вручную заполненный администратором**, а не реальный игровой онлайн.
- `GET /health` — проверка работы процесса.
- `GET /login`, `/register`, `/account` — учётные записи сайта.

При общем запуске включён локальный единый вход на форум. Порядок работы и настройки HTTPS: [SSO](../docs/SSO.md).

## Статус

**Рабочая локальная версия, не публичный релиз.** Покупки, игровые персонажи и реальный мониторинг онлайна не подключены. Перед публикацией необходимы HTTPS, защита от спама, резервные копии и аудит безопасности.
