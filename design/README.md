# Оформление OBSIDIAN RUSSIA

Здесь собраны исходные бренд-материалы проекта:

- `branding/ava.jpg` — эмблема и аватар сообщества.
- `branding/cover.jpg` — обложка.
- `posts/images/` — графика публикаций, отсортированная по датам.
- `posts/text/` — тексты публикаций, включая исправленные ссылки официальных сообществ.

Сайт, форум и Wiki уже содержат собственные копии необходимых изображений в папках `static/`. Это намеренно: каждый веб-сервис может разворачиваться самостоятельно. Не удаляйте эти копии без обновления путей в приложениях.

Официальные сообщества: [VK](https://vk.ru/obsidian_brussia) · [Telegram](https://t.me/obsidian_brussia).
