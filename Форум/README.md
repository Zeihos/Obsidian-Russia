# Форум OBSIDIAN RUSSIA

[← Главная страница репозитория](../README.md) · [Единый вход](../docs/SSO.md)

Самостоятельный форум с категориями и разделами, темами, ответами, поиском, подписками, жалобами и административной модерацией.

## Запуск

Из корня репозитория:

```bash
python dev.py run
```

Форум будет доступен по адресу **http://localhost:8090**. Для отдельного запуска из этой папки используйте `start.bat` или `python app.py`.

Создание администратора: `python dev.py admin forum`. Административная панель: `http://localhost:8090/admin`.

## Учётные записи

Существуют два режима входа:

1. Локальная регистрация и вход самого форума.
2. **SSO с основного сайта** — через одноразовый код без передачи форуму пароля.

Ранее созданные профили не объединяются по совпадающему email или имени. SSO-профили создаются с правами обычных участников; администраторские права не наследуются с сайта.

## Данные

Локально через `dev.py` база расположена в `.runtime/forum/`. При отдельном запуске используется `Форум/data/`, если не задан `OBFORUM_DATA_DIR`.

Резервное копирование из корня:

```bash
python dev.py backup forum
```

Полезные маршруты: `/latest`, `/members`, `/api/stats` и `/health`.

## Статус

Форум локально работоспособен, но **ещё не готов к безнадзорному публичному размещению**. Нужны HTTPS, антиспам, управление отзывом сессий и проверка модерации перед массовым запуском.
