# Игровой мод — архив исходных материалов

В каталоге `legacy/` сохранён архив, загруженный в первоначальную версию репозитория:

`Obsidian Russia - Блэк Раша.rar`.

**Это не протестированная сборка игрового сервера.** Содержимое архива, возможность сборки, безопасность и права на сторонние ресурсы здесь пока не подтверждены. Не запускайте полученные из него исполняемые файлы на основном компьютере или рабочем сервере без проверки.

Сайт, форум и Wiki не требуют этого архива для запуска. В будущем проверенные исходники игрового сервера можно вынести в отдельную структуру `game/server/`, с документацией сборки и лицензиями сторонних компонентов.

Не публикуйте в репозитории ключи API, данные игроков или рабочие базы.
