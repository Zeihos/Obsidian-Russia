# Wiki OBSIDIAN RUSSIA

[← Главная страница репозитория](../README.md) · [Развёртывание](../docs/DEPLOYMENT.md)

База знаний проекта: статьи с историей редакций, категории, поиск, каталоги транспорта, скинов, недвижимости, бизнесов, профессий и предметов.

## Запуск

Из корня репозитория:

```bash
python dev.py run
```

Wiki доступна по адресу **http://localhost:8100**. Для отдельного запуска из этой папки используйте `start.bat` или `python app.py`.

Создание администратора: `python dev.py admin wiki`. Панель редактора: `http://localhost:8100/admin`.

## Содержание

Начальные статьи — **редакционные заготовки**. Не воспринимайте их как подтверждение работы игровых механик, цен или характеристик ещё не запущенного сервера. В редакторе можно создавать и публиковать статьи, оставлять черновики, загружать изображения и восстанавливать предыдущие версии.

Wiki использует **отдельные аккаунты редакторов** и не даёт всем участникам форума право изменять статьи.

## Данные и резервные копии

База в общем локальном режиме — `.runtime/wiki/`. При отдельном запуске — `Вики/data/` (или значение `OBWIKI_DATA_DIR`).

```bash
python dev.py backup wiki
```

**Важно:** изображения хранятся отдельно в `Вики/static/uploads/`. Их необходимо резервировать вместе с базой; одной SQLite-копии недостаточно.

Полезные страницы: `/articles`, `/catalog`, `/search`, `/api/stats`.

Дополнительная инструкция: [УСТАНОВКА.txt](%D0%A3%D0%A1%D0%A2%D0%90%D0%9D%D0%9E%D0%92%D0%9A%D0%90.txt).

## Статус

Локальный движок протестирован. Для публикации необходимы HTTPS, дополнительная защита редакторских аккаунтов, редакционная проверка материалов и юридические настройки.
